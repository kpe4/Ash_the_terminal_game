# ПЕПЕЛ

Маленький монохромный рогалик для терминала

```
        ░
       ░▒░
      ░▒▓▒░
     ░▒▓█▓▒░
     ░▒▓█▓▒░
      ░▒▓▒░
       ░▒░
        ░
     П Е П Е Л
```

## Запуск

Нужен Python 3.10 или новее

```bash
python pepel.py
```

На Windows можно просто дважды кликнуть `play.bat`.

Рекомендуется Windows Terminal и шрифт с поддержкой псевдографики
(Cascadia Mono, Consolas, Lucida Console). Минимальный размер окна — 74 × 24

## Управление

| Клавиши | Действие |
| --- | --- |
| стрелки, WASD, HJKL | движение и удар |
| `1` | выпить зелье |
| `2` | прочесть свиток (открывает весь этаж) |
| `g` | поднять предмет |
| `.` | подождать один ход |
| `>` или Enter на лестнице | спуститься ниже |
| `?` | справка |
| `q` | выйти |

Русская раскладка поддерживается: ЦФЫВ работают как WASD, Ю — как `>`
Золото подбирается само, остальное — по клавише `g`

## Что внутри

- процедурные этажи из комнат и коридоров;
- поле зрения с освещением: близкое ярче, далёкое тусклее, исследованное
  запоминается;
- пошаговый бой, опыт, уровни, зелья, свитки, клинки и броня;
- шесть видов чудовищ и страж на последнем этаже;
- только оттенки серого — от `#1c1c1c` до чистого белого

## Мелочи

```bash
python pepel.py --demo 100x30   # один кадр без запуска игры
python pepel.py --selftest      # проверка генерации и правил
```

Структура кода:

```
pepel.py          точка входа, игровой цикл
game/screen.py    палитра, кадровый буфер, ввод
game/dungeon.py   генерация подземелья, поле зрения
game/entities.py  игрок, чудовища, предметы
game/game.py      правила: ходы, бой, этажи
game/paint.py     отрисовка игрового экрана
game/screens.py   заставка, справка, финал
```
